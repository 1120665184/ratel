面向数据分析场景的组件层级和类型定义

组件层级结构

组件树示意
Dashboard
StatCard
title · value · trend · icon
Chart
chartType: bar|line|pie|area · data · title
DataTable
columns · data · title · bordered
TextBlock
content · variant: plain|heading|info|warning|error
Section
title · description · layout: row|column
→ 可嵌套任意子组件

组件清单与用途

组件 用途 关键Props 子组件
Dashboard 根容器，定义标题和整体布局 title, description 任意
Section 分组容器，支持行列布局 title, description, layout(row/column) 任意
StatCard 统计指标卡片 title, value, trend(up/down/flat), changeRate, icon 无
Chart 图表组件（ECharts渲染） chartType(bar/line/pie/area), title, data, options 无
DataTable 数据列表 title, columns[], data[], bordered, striped 无
TextBlock 文本/提示/说明 content, variant(plain/heading/info/warning/error) 无

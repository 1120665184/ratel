修订版架构设计

根据反馈调整：无新微服务、AiOutputPanel 重写、SkillBox 按需加载组件文档

1. 前端服务层（pub/sub 模式）

与现有 human-approval 同模式
// services/agent-output/index.ts
type AgentOutputPayload = {
patch: string; // JSONL patch 行
};
// 监听器集合
const listeners = new Set<(p: AgentOutputPayload) => void>();
export function dispatchAgentOutput(p: AgentOutputPayload) {
listeners.forEach(fn => fn(p));
}
export function onAgentOutput(fn: (p: AgentOutputPayload) => void) {
listeners.add(fn);
return () => listeners.delete(fn);
}

与 human-approval、ask-user-question 完全同模式，只是数据类型不同。

2. AiOutputPanel 重写方案

去掉 iframe，直接用 json-render Renderer
// AiOutputPanel/index.tsx
import { Renderer, createSpecStreamCompiler } from '@json-render/react';
import { registry } from './registry'; // catalog+registry
import { onAgentOutput } from '@/services/agent-output';
// 流式编译器
const compiler = createSpecStreamCompiler();
// 监听 AGENT_OUTPUT 事件，逐 patch 应用
useEffect(() => {
return onAgentOutput(({ patch }) => {
compiler.push(patch);
});
}, []);
// 渲染
return <Renderer spec={compiler.getResult()} registry={registry} />;

3. 后端 SkillBox 组件技能

按需加载，减少上下文消耗

SkillBox 注册
// OutputViewAgent.build()
SkillBox skillBox = new SkillBox(toolkit);
skillBox.registration()
.skill(loadSkill(
"stat_card",
"展示统计指标时加载",
"stat-card.md"))
.skill(loadSkill(
"chart",
"展示图表时加载",
"chart.md"))
// ... 其他组件技能
.skill(loadSkill(
"spec_format",
"必须加载: spec格式说明",
"spec-format.md"))
.apply();
spec_format 技能始终标记为"必须加载"，确保 LLM 了解 spec 格式。其他组件技能按需加载，只在 LLM 判断需要时才读取，大幅减少上下文消耗。

修订版端到端流程

简化后的数据流
1 CentralBrain 调用 OutputViewAgent
2 LLM 按需加载相关组件 skill（如 chart.md、data-table.md）
3 LLM 输出 json-render spec（JSONL patch 逐行）
4 OutputViewEventHandlerHook 拦截 → 发送 AGENT_OUTPUT Custom 事件
5 前端 WebToolEventListener 接收 → dispatchAgentOutput()
6 AiOutputPanel 监听 → createSpecStreamCompiler.push() 渐进渲染
7 Renderer (catalog + registry) → 7组件主题化渲染

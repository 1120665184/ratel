skill.md 内容示意

# 视图输出技能 你是一个专门将内容以精美可视化界面展示的智能体。 你输出的内容将以前端组件的形式渲染给用户。 ## 支持的组件 | 组件 | 用途 | 详细文档 | |------|------|----------| | Dashboard | 根容器，定义标题和整体布局 | @components/dashboard.md | | Section | 分组容器，支持行列布局 | @components/section.md | | StatCard | 统计指标卡片（数值+趋势） | @components/stat-card.md | | Chart | 图表（柱状/折线/饼图/面积） | @charts/chart.md | | DataTable | 数据列表 | @components/data-table.md | | TextBlock | 文本/提示/说明 | @components/text-block.md | | FlowChart | 流程图 | @components/flow-chart.md | ## Spec 格式规范（必读） 详见 @specs/spec-format.md ## 使用规则 1. 必须先阅读 @specs/spec-format.md 了解 spec 输出格式 2. 根据展示需求选择合适的组件，阅读对应详细文档 3. 输出符合 spec 格式的 JSON，前端将流式渲染 4. 优先使用 Section 分组，保持布局清晰 5. 统计数据用 StatCard，趋势用 Chart，明细用 DataTable

SkillBox 注册方式

// OutputViewAgent.build()
SkillBox skillBox = new SkillBox(toolkit);
skillBox.registration()
.skill(AgentSkill.builder()
.name("output_view")
.description("将回复内容以可视化界面展示给用户时加载此技能")
.skillContent(loadResource("output-view/skill.md"))
.build())
.apply();

LLM 加载行为

按需读取的加载链路
Step 1 LLM 判断需要可视化输出 → 加载 output_view skill
看到组件目录总览：7个组件 + 引用路径
Step 2 读取 spec-format.md（必须） + 按需读取组件详细文档
例如：展示统计 → 读 stat-card.md + chart.md
Step 3 基于文档输出正确的 spec JSON

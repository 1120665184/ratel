流式渲染时序

从 chunk 到渲染的时序流程
1. CentralBrain 调用 OutputViewAgent 子智能体
OutputViewAgent 收到任务描述（如"展示安全事件统计"）
2. OutputViewAgent 推理（ReAct 循环）
LLM 基于 sysPrompt（含 catalog.prompt()）生成 spec
输出格式：JSONL patch 逐行流式输出
3. OutputViewEventHandlerHook 拦截 ActingChunkEvent
识别 OutputViewAgent 的 TextBlock
将 textBlock.text 作为 AGENT_OUTPUT value 发送
4. 前端 WebToolEventListener 接收 AGENT_OUTPUT
dispatch 到 agent-output 服务
5. AiOutputPanel 监听 agent-output 事件
createSpecStreamCompiler.push(chunk)
→ result 渐进更新 → Renderer 重新渲染
6. 流式结束
compiler.getResult() 获取最终完整 spec

关键设计决策

后端不生成 HTML
后端只输出 json-render spec JSON，前端负责渲染。解耦数据与展示，支持主题切换。
catalog 定义是唯一事实来源
前端 catalog 定义 → catalog.prompt() 生成 AI 提示词 → 后端 sysPrompt 引用。一份定义，两端使用。
JSONL patch 流式传输
LLM 输出的每个 patch 行通过 AGENT_OUTPUT 事件逐个发送，前端 createSpecStreamCompiler 逐行应用，实现渐进式渲染。
图表渲染用 ECharts
Chart 和 FlowChart 组件内部用 ECharts 渲染（项目已安装 echarts），spec 只描述数据，渲染逻辑封装在组件内。

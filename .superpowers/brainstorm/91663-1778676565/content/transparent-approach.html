A

整体毛玻璃

Header + 消息区 + 输入框全部半透明毛玻璃，视觉一致性强，透出桌面背景。文字颜色需适配为浅色以保证可读性。

优点

  • 视觉统一、高端感强
  • 透明效果最明显

缺点

  • 暗色桌面时文字可能不清晰
  • 需要调整文字/按钮颜色
B

Header/输入框不透明 + 内容区毛玻璃

操作区域（Header、输入框）保持不透明确保可用性，仅消息内容区域使用毛玻璃效果。

优点

  • 可读性好，操作区始终清晰
  • 改动量小，兼容现有样式

缺点

  • 视觉统一性稍弱
  • 透明效果不够明显
C

自适应毛玻璃（深色桌面浅色文字 / 浅色桌面深色文字）

整体毛玻璃 + 自动检测背景亮度动态切换文字颜色，兼顾美观和可读性。

优点

  • 视觉统一 + 可读性好
  • 智能适配不同背景

缺点

  • 实现复杂度较高
  • 背景快速变化时可能闪烁

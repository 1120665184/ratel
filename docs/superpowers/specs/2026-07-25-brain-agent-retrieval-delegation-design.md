# 中枢大脑检索委派设计

## 目标

将中枢大脑调整为任务编排者：在不影响主任务推进的前提下，优先将知识库与数据库事实检索委派给 `doOddJobs`，以降低主智能体的上下文占用；界面操作仍必须由主智能体直接完成。

## 职责边界

### 主智能体

- 理解用户意图，选择任务路径，整合事实并对用户输出最终答复。
- 处理所有可视化界面任务，包括页面导航、读取界面、点击、输入和修改数据。
- 对知识库检索、数据库查询及二者组合的只读事实收集，优先委派 `doOddJobs`。
- 当子智能体不可用、返回信息不足，或检索结果必须与正在进行的界面操作即时结合时，可自行加载对应检索 Skill 作为回退。

### doOddJobs 子智能体

- 仅执行知识库检索、数据库查询或二者组合的只读事实收集。
- 必须遵守 `knowledge_search` 的语言转换、上下文补全、引用与事实边界规则。
- 必须遵守 `database_search` 的权限校验、表结构确认、只读 SQL、数据源边界与结果限制规则。
- 不执行页面导航、读取、点击、输入或数据修改；不替主智能体完成最终的用户答复或业务决策。

## Skill 路由

### database_search

用于获取系统中实时或持久化的业务数据，包括记录明细、数量统计、聚合分析、状态核验、数据之间的关联查询，以及需要用数据库事实验证的问题。它不是制度、流程或操作说明的来源，并且只允许读取数据。

### knowledge_search

用于获取知识库中已沉淀的制度、规范、流程、操作手册、产品说明、FAQ 与历史文档内容。它不是实时业务数据来源，答案只能基于检索片段及其补全上下文。

当用户同时询问业务规则和实际数据时，子智能体可以组合使用两个 Skill：知识库提供规则依据，数据库提供当前事实；任一侧未检索到足够证据时都必须如实说明。

## 主系统提示词要求

- 回答必须真实、可追溯，禁止编造；无数据、无权限或证据不足时明确说明。
- 非视图检索任务优先委派 `doOddJobs`，保持主智能体专注于任务编排与答复。
- 视图操作禁止调用任何子智能体，必须由主智能体自行执行。
- 继续保留已有的澄清、内容面板展示与用户权限原则，但使其与新的委派边界一致。

## 验证

- 编译 `business-security/business-security-server` 及其依赖模块。
- 静态检查子智能体描述、两个 Skill 的 description 和主系统提示词均包含上述路由与禁止委派规则。
